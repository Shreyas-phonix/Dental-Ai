# User guide

## Uploading a dental X-ray

1. Open the Analyze page.
2. Drag and drop an OPG image or browse your computer.
3. Confirm the image preview loads correctly.
4. Click Analyze.
5. Wait for the model to run and review the result.

## Interpreting output

- Estimated age is provided as a continuous value in years.
- Grad-CAM heatmap shows regions contributing most strongly to the model prediction.
- Explanation is for research interpretation only and does not establish causality.

## Responsible use notice

This tool is not a definitive medical, forensic, or legal determination.
