# DentalAge AI — project overview

## Objective

Build a complete working prototype for explainable dental age estimation from panoramic radiographs.

## Current implementation status

This repository contains the foundational architecture and working minimal prototype for:

- FastAPI backend
- SQLite database
- PyTorch regression model
- Grad-CAM-based explainability pipeline
- React frontend dashboard
- Docker deployment scaffold
- Documentation and tests

## Implementation plan

1. Define the repository structure and deployment setup.
2. Create the backend API, validation, and SQLite persistence layer.
3. Implement the ML preprocessing, model, training, evaluation, and explainability pipeline.
4. Build the frontend dashboard for upload, preview, analysis, heatmap display, and history.
5. Document the dataset strategy, responsible-use disclaimers, and limitations.
6. Add tests and deployment files.

## Responsible use

The model is a research prototype and should not be used as a definitive forensic or clinical determination.
